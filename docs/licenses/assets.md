### 使用位置

- `web/src/ui/glass/GlassDebugPanel.css:414` — `@font-face { font-family: 'GlassesMirror'; src: url('/fonts/glassesmirror.ttf') format('truetype'); }`
- `web/src/ui/glass/GlassScenePreview.tsx:19` — `const PREVIEW_FONT = '"GlassesMirror", "Cascadia Code", "Consolas", "Courier New", monospace'`

### 改名情况

字体文件 renamed `glassesmirror.ttf`（原文件名推测为 `SUSEMono-Thin.ttf`），`font-family` 声明为 `'GlassesMirror'` 而非 `SUSE Mono Thin`。OFL §3 禁止 Modified Version 使用 Reserved Font Name；此处既未修改字体、也未使用保留名（SUSE font repo 未声明 RFN），改名行为合规。

### ✅ 风险项 A1: 仓库缺少 OFL-1.1 许可文本

OFL §2 要求: "each copy contains the above copyright notice and this license. These can be included either as stand-alone text files, human-readable headers or in the appropriate machine-readable metadata fields within text or binary files."

字体元数据已嵌入许可声明（name ID 13），满足「machine-readable metadata fields」选项。但为清晰和可审计性，**建议在 `web/public/fonts/` 目录放置 `OFL.txt`**（标准 SIL OFL 1.1 全文 + 版权行），或在 About 第三方声明页面包含该文本。

**严重度**: 低（元数据已满足最小要求，推荐补文件以增强合规性）。

## 2. 图标管线: web/scripts/download-atom-icons.cjs

### 上游仓库与许可

| 上游 | 仓库 | 许可证 | 核验 |
|---|---|---|---|
| 图标映射数据 | github.com/AtomMaterialUI/a-file-icon-vscode | **MIT** | 已核验 LICENSE.md: "Copyright (c) 2023 Elior 'Mallowigi' Boukhobza and Philipp 'PKief' Kief" |
| SVG 图标资产 | github.com/mallowigi/iconGenerator | **MIT** | 已核验 LICENSE: "Copyright (c) 2017-2019 Elior Boukhobza" |

### 生成产物: web/src/ui/panels/atom-icons/iconData.ts

**每枚 SVG 内嵌完整 MIT 通知**，例如:
```
<!--
  - The MIT License (MIT)
  - Copyright (c) 2015-2024 Elior "Mallowigi" Boukhobza
  - ...
  -->
```

此通知覆盖所有图标文件。署名义务已满足。

### ✅ 风险项 A2: 生成脚本头部仅列 Source URL，未列许可证

```
// AUTO-GENERATED by scripts/download-atom-icons.cjs
// Source: https://github.com/AtomMaterialUI/a-file-icon-vscode
// Icons: https://github.com/mallowigi/iconGenerator
// DO NOT EDIT MANUALLY
```

建议在注释中增加一行 `// License: MIT (see upstream repos for copyright)`。虽 SVG 本体已内嵌通知，header 增加可提升可审计性。

**严重度**: 低。

### ✅ 风险项 A3: 图标系谱署名（Credits 追溯）

iconGenerator 的 README Credits 列出:
- FontAwesome 4.7.0（CC BY 4.0）
- Octicons（MIT）
- Material Design Icons（Apache-2.0 / Pictogrammers Free License）
- Devicons（MIT）
- File-Icons / Atom File Icons / Material Icon Theme

若个别图标为逐字派生自上述来源，其来源许可的署名条件可能适用。该项目直接将 SVG 从 iconGenerator 复制（非对 MDI/FA 的直接调用），因此上述来源的许可证文字不直接约束本项目的分发，但保留 Credits 声明是良好实践。

**严重度**: 低（建议保留系谱声明）。
