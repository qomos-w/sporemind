工作台模式 · Workbench Board

构建 / 应用 / 工作台

工作台是第三个启动模式：进入后整个界面清空，只留一块黑板，原有的页面与应用变成黑板上的圆角卡片。黑板完全由 agent 控制，并用一套注意力优先机制决定每张卡片的位置、大小与亮度。下面是四个方向。

方案 A · 引力轨道

注意力最高的卡片占据黑板中心，其余卡片按注意力远近散布在椭圆轨道上。注意力越高越靠内、越大、越亮。

中心聚焦 · 轨道排布

方案 B · 注意力热场

自由画布，卡片像图钉一样散落。注意力塑造一张热力图：热区卡片放大发亮，冷区卡片退到暗处缩小。

自由画布 · 热力衰减

方案 C · 注意力传送带

三条纵带：现在 / 进行中 / 背景。卡片按注意力从左向右流动，注意力衰减时自动降级到下一带。

分带流动 · 优先级队列

方案 D · 黑板板书

agent 以板书方式在黑板上画卡片与连线，串起卡片之间的因果关系。注意力 = 板书强调的力度。

关系连线 · 叙事编排
